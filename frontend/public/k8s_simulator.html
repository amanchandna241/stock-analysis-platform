📐 Production Rules of Thumb

• 1 Process Per Pod: Run 1 FastAPI Uvicorn process per container. Let Kubernetes scale pods horizontally instead of multi-threading inside a fat container.

• Requests vs Limits: Set CPU request = 500m and limit = 1000m. Never leave limits blank or risk CPU starvation.

• PDB `minAvailable: 2`: Ensures that node rolling upgrades and Karpenter consolidation never drain the last available backend replica.
